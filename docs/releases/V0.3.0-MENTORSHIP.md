# GTD Hub v0.3.0 — Mentorship workflow

## Delivered
- PostgreSQL-backed mentor profiles, mentorship requests and active connections.
- Mentor directory with search and expertise filtering.
- Member request creation and cancellation while pending.
- Mentor acceptance and decline with optional response.
- Automatic connection creation on acceptance.
- Member, mentor and Programme Administrator request/connection views.
- Institution scoping for mentor discovery and ownership checks for mentor decisions.
- React mentorship workspace connected to the FastAPI API.

## Deployment
1. Back up the target PostgreSQL database.
2. Deploy backend code.
3. Run `alembic upgrade head` from the backend service.
4. Run the idempotent seed command to add the three fictional mentor accounts/profiles.
5. Deploy the frontend build with the existing API base URL.

## Safety
This is a fictional proposal demonstrator. Do not enter real safeguarding disclosures or sensitive personal information. The mentorship module is not a live institutional service.

## Verification still required
