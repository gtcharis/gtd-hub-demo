# GTD Hub v0.3.5 — Administration, Institutional Insights & M&E

**Release status:** implementation candidate; local PostgreSQL integration tests and deployment validation remain required.

## Post-submission demonstrator enhancement

This release extends the demonstrator after the original consultancy application was submitted. It is an enhancement to support evaluation and should not be represented as a feature already promised in the original application.

## Included capabilities

- Administration dashboard counts sourced from current database records.
- User directory, account creation, role updates, institution assignment, activation and deactivation.
- Institution creation, editing and activation/deactivation for Programme Administrators.
- Organisation Administrator user management restricted to their own institution.
- Programme Administrator programme-wide administration.
- Session revocation when account access, role, institution or activation state changes.
- Administrative audit events for user and institution changes and M&E exports.
- Aggregate indicators for registered/active accounts, mentors, mentorship requests/connections, community discussions and published learning resources.
- Aggregate CSV export.

## Safeguarding and data boundaries

- Dashboards and M&E exports do not query or expose case narratives, contact details, case references or identifiable case-level records.
- No automated risk scoring, triage, referrals, escalation or other safeguarding decisions are introduced.
- Human personnel retain all safeguarding decision-making authority.
- Metrics describe demonstrator records and are not participant outcome or programme impact measures.
- User account creation requires an administrator-supplied password; passwords are never returned by administrative APIs.
- Administrative audit metadata is allowlisted and excludes credentials and case content.

- `GET /api/v1/admin/audit`
